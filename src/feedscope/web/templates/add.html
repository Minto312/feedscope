Android（Chrome）— 共有シートに出す

Chrome のメニューから「アプリをインストール / ホーム画面に追加」を実行するだけです。 インストール後、他アプリの共有メニューに feedscope が現れます。 （未インストールだと共有シートには出ません）

iPhone（Safari）— ショートカットApp を使う

iOS は Safari を含む全ブラウザが Web Share Target に非対応のため、 ショートカットApp で共有シートに追加します（1 回だけの設定）。

  1. ショートカットApp →「＋」で新規作成
  2. 画面上部の情報アイコン →「共有シートに表示」をオン → 受け取るタイプを URL のみにする
  3. アクション「URL の内容を取得」を追加
  4. URL 欄に {{ request.url_root }}add を入力
  5. 「詳細を表示」→ 方法を POST、本文を フォーム にする
  6. フィールドを追加: キー url、値に「ショートカットの入力」を指定
  7. 名前を「feedscope に保存」にして完了

以後、Safari の共有シートから「feedscope に保存」でライブラリに入ります。
